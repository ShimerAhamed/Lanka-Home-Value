# Demo Script - LankaHomeValue

Use this simple script during the final university demonstration.

## Before Starting

Check:

- MongoDB is running.
- `models/house_price_model.pkl` exists.
- Dataset is available if training is needed.
- Frontend, backend, and ML API dependencies are installed.

## Step 1 - Start FastAPI ML API

Open Terminal 1:

```powershell
cd C:\Users\HP\LankaHomeValue\ml-api
uvicorn api:app --reload
```

Say:

```text
This starts the Python FastAPI service, which loads the trained machine learning model.
```

## Step 2 - Start Express Backend

Open Terminal 2:

```powershell
cd C:\Users\HP\LankaHomeValue\backend
npm run dev
```

Say:

```text
This starts the Express backend. It connects the React frontend, FastAPI prediction service, and MongoDB database.
```

## Step 3 - Start React Frontend

Open Terminal 3:

```powershell
cd C:\Users\HP\LankaHomeValue\frontend
npm run dev
```

Say:

```text
This starts the React frontend where users enter house details.
```

## Step 4 - Open Browser

Open:

```text
http://localhost:5173
```

Show the home page.

Say:

```text
This is the LankaHomeValue web application for predicting Sri Lankan house selling prices.
```

## Step 5 - Enter House Details

Go to:

```text
Predict House Price
```

Enter sample details:

- District: Colombo
- Area: Nugegoda
- Perch: 10
- Bedrooms: 3
- Bathrooms: 2
- House size: 1600
- Condition: Good
- Furnishing: Semi Furnished
- Location Category: Urban

Say:

```text
The form validates missing and invalid values before sending data to the backend.
```

## Step 6 - Click Predict

Click:

```text
Predict Price
```

Show:

- Predicted House Selling Price
- LKR formatting
- Price Category badge
- Disclaimer

Say:

```text
The predicted value is generated by the trained machine learning model and is not an official valuation.
```

## Step 7 - Show Prediction History

Open:

```text
Prediction History
```

Show:

- Latest prediction records
- District
- Area
- Predicted price
- Category
- Date
- Delete button

Say:

```text
Every prediction is saved in MongoDB and can be viewed later.
```

## Step 8 - Show Backend Logs

Open the Express backend terminal.

Say:

```text
The backend handles requests, calls FastAPI, and stores history in MongoDB.
```

## Step 9 - Show API Response

Open browser or Postman:

```text
GET http://localhost:5000/api/health
```

Say:

```text
The health endpoint confirms that the backend, Python API, and database are connected.
```

## Step 10 - Explain Architecture

Say:

```text
The flow is User to React, React to Express backend, Express to FastAPI ML API, FastAPI to trained model, and then the result is returned to the user. MongoDB stores prediction history.
```

## Closing Statement

```text
LankaHomeValue demonstrates how machine learning can be integrated with a full-stack web application to estimate Sri Lankan house selling prices.
```
