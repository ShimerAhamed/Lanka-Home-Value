# Viva Short Answers - LankaHomeValue

## What is your project purpose?

LankaHomeValue predicts estimated house selling prices in Sri Lanka using machine learning. It helps users get a quick price estimate before making property decisions.

## What is your prediction target?

The prediction target is `house_selling_price_lkr`, which means the house selling price in Sri Lankan Rupees.

## What dataset did you use?

I used `Updated House Selling Dataset.csv`, which contains Sri Lankan house details such as district, area, land size, bedrooms, bathrooms, house size, facilities, condition, and selling price.

## What machine learning models did you use?

I trained and compared Linear Regression, Decision Tree Regressor, Random Forest Regressor, and Gradient Boosting Regressor.

## What is the best model and accuracy?

The best model is Gradient Boosting Regressor. It achieved an R2 score of about `0.9671`, with RMSE around `4,538,167.73`.

## Why was Gradient Boosting selected?

It gave the highest R2 score and strong RMSE performance. It also handles nonlinear relationships better than simple linear regression.

## Explain the system architecture.

The flow is:

```text
User -> React -> Express Backend -> FastAPI ML API -> Trained Model -> Result
```

MongoDB stores the prediction history.

## What technologies did you use?

I used React, Node.js, Express, MongoDB, FastAPI, Python, Scikit-learn, Pandas, NumPy, and Joblib.

## What are the limitations?

The prediction depends on dataset quality, market prices can change, and the system does not replace official property valuation.

## What are future improvements?

Future improvements include adding more updated data, map-based location features, user login, admin dashboard, charts, and cloud deployment.

## Is this an official valuation?

No. It is only an estimated value generated by a machine learning model.
