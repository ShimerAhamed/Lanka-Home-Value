# LankaHomeValue - AI-Based House Price Prediction System

LankaHomeValue is a final year project for predicting house selling prices in Sri Lanka. The system uses a trained machine learning model to estimate `house_selling_price_lkr` and returns a price category: Low, Medium, High, or Premium.

The prediction is an estimate generated by a machine learning model. It is not an official property valuation.

## System Architecture

```text
React frontend -> Express backend -> FastAPI ML API -> trained model
```

## React Frontend Usage

1. Open `http://localhost:5173`.
2. Click `Predict House Price`.
3. Fill all required form fields.
4. Click `Predict Price`.
5. View the formatted LKR price, category badge, and disclaimer.
6. Open `Prediction History` to view saved MongoDB records.
7. Use `Refresh` to reload history.
8. Use `Delete` to remove a history record.
