# LankaHomeValue - AI-Based House Price Prediction System for Sri Lanka

LankaHomeValue is a final year project that predicts estimated house selling prices in Sri Lanka using machine learning. The system includes a React frontend, Node.js Express backend, Python FastAPI ML API, MongoDB database, trained model, and prediction history.

The prediction result is an estimated value generated by a machine learning model. It is not an official property valuation.

## Project Overview

The user enters house details through the React web interface. The data is sent to the Express backend, then forwarded to the FastAPI ML API. The trained model predicts `house_selling_price_lkr`, and the result is returned to the frontend. The Express backend also saves each prediction in MongoDB.

System flow:

```text
User -> React Frontend -> Express Backend -> FastAPI ML API -> ML Model -> Result
```

## Installation Guide

This final submission ZIP does not include `node_modules/`, `.venv/`,
`__pycache__/`, or real `.env` files. After extracting the project, install the
dependencies again using the commands below.

### 1. ML API Setup

```powershell
cd C:\Users\HP\LankaHomeValue\ml-api
pip install -r requirements.txt
python train_model.py
uvicorn api:app --reload
```

FastAPI runs at:

```text
http://127.0.0.1:8000
```

### 2. Backend Setup

Create `backend/.env` using `.env.example`.

```powershell
cd C:\Users\HP\LankaHomeValue\backend
npm install
npm run dev
```

If PowerShell blocks npm, use:

```powershell
npm.cmd install
npm.cmd run dev
```

Express backend runs at:

```text
http://localhost:5000
```

### 3. Frontend Setup

```powershell
cd C:\Users\HP\LankaHomeValue\frontend
npm install
npm run dev
```

React frontend runs at:

```text
http://localhost:5173
```

## Usage Guide

1. Start MongoDB.
2. Start FastAPI from `ml-api`.
3. Start Express backend from `backend`.
4. Start React frontend from `frontend`.
5. Open `http://localhost:5173`.
6. Go to `Predict House Price`.
7. Enter house details.
8. Click `Predict Price`.
9. View predicted LKR price and category.
10. Go to `Prediction History` to view saved records.
